# AHİ.3D

AHİ.3D 3D Baskı ve Tasarım Atölyesi web sitesi. Ziyaretçiler ürünleri görüp WhatsApp'tan fiyat sorabilir.

- `index.html`: ana sayfa
- `urun/NN.html`: her ürünün kendi sayfası (WhatsApp mesajında ürün fotoğrafının kart olarak görünmesi için)
- `tools/make_product_pages.py`: ürün sayfalarını yeniden üretir
